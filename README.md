# 📊 AttendX — Faculty Attendance Management System

AttendX is a Flask-based web application designed to help faculty manage student attendance efficiently through a clean, modern, and interactive dashboard. It simplifies the process of tracking, analyzing, and managing attendance data in an organized way.

## 🚀 Features

- 📋 Student Management system  
- 📝 Mark Attendance (with voice recording support)  
- 📊 View attendance records  
- ⚠️ At-Risk student identification  
- 📥 Download attendance reports (Excel)  
- 📅 Monthly Attendance Calendar  
- 📈 Real-time dashboard statistics  

## 🖥 Dashboard Highlights

- Sidebar navigation for all modules  
- Welcome topbar with faculty name  
- Overview cards (Total Students, Attendance Days, Present Today)  
- Department-wise student distribution  
- Quick action cards for faster workflow  
- Interactive attendance calendar  
- Today's date display  

## 🛠 Tech Stack

- **Backend:** Python (Flask)  
- **Frontend:** HTML, CSS (Jinja2 Templates)  
- **Fonts:** Google Fonts (Plus Jakarta Sans, Great Vibes)  
- **Storage:** JSON  

## ▶️ How to Run

1. Clone the repository  
2. Install dependencies (if any)  
3. Run `app.py`  
4. Open in browser at `http://127.0.0.1:5000`
